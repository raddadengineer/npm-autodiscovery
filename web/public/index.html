Setup Guides & Quickstarts

Production-ready configurations for Docker, Proxmox VE, LXD, and Multi-Node Clusters.

Complete production stack: Nginx Proxy Manager, Auto-Discovery Sidecar, HealthChecked microservice with middlewares, and L4 stream:

version: '3.8'

services:
  # 1. Nginx Proxy Manager
  npm:
    image: 'jc21/nginx-proxy-manager:latest'
    container_name: nginx-proxy-manager
    restart: unless-stopped
    ports:
      - '80:80'
      - '443:443'
      - '81:81'
      - '25565:25565' # L4 Game/Stream Port
    volumes:
      - npm_data:/data
      - npm_letsencrypt:/etc/letsencrypt
    networks:
      - npm-network

  # 2. NPM Auto-Discovery Agent (v2.0)
  npm-autodiscovery:
    image: 'raddadengineer/npm-autodiscovery:latest'
    container_name: npm-autodiscovery
    restart: unless-stopped
    ports:
      - '8080:8080' # Agent Dashboard
    env_file:
      - .env
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock:ro
      - ./data:/data
    networks:
      - npm-network

  # 3. Example Microservice with v2.0 Features
  enterprise-api:
    image: company/portal-api:latest
    container_name: portal-api
    networks:
      - npm-network
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8080/healthz"]
      interval: 5s
      timeout: 3s
      start_period: 20s
    labels:
      # Ingress & SSL
      - "npm.frontend.domain=portal.company.com"
      - "npm.frontend.port=8080"
      - "npm.ssl.enabled=true"
      - "npm.websocket=true"
      # Zero-502 Cold-Start Resilience
      - "npm.healthcheck.enabled=true"
      - "npm.healthcheck.timeout=45s"
      # Declarative Middlewares
      - "npm.middleware.strip_prefix=/api"
      - "npm.middleware.rate_limit=20r/s"
      - "npm.middleware.cors=true"
      - "npm.middleware.security_headers=true"
      # Custom Location Subpath
      - "npm.frontend.path=/api"

networks:
  npm-network:
    name: npm-network

volumes:
  npm_data:
  npm_letsencrypt:

Proxmox VE LXC container and QEMU Virtual Machine discovery using API Token authentication and GUI tags or Notes (Description):

⚡ Quick Tip: In Proxmox VE, you can configure discovery using either Tags (comma-separated list in Web GUI or CLI) OR Notes (multi-line YAML block in the container/VM Notes textarea). Both LXCs and QEMU VMs are fully supported!

🏷️ Method 1: Proxmox Web GUI Tags (Comma-Separated)

In the Proxmox Web GUI, select your LXC or VM, click Tags in the top header, and paste comma-separated key=value pairs: 

# Example A: Standard Web App (HTTP on port 8080 with SSL & WebSockets)
npm.domain=adguard.homelab.arpa, npm.port=8080, npm.ssl=true, npm.websocket=true

# Example B: Multi-Domain Ingress with Forced HTTPS & Exploit Shielding
npm.domain=vault.homelab.arpa, bitwarden.homelab.arpa, npm.port=8000, npm.ssl=true, npm.ssl_forced=true, npm.block_exploits=true

# Example C: Layer 4 TCP Stream (e.g. Minecraft 25565 or PostgreSQL 5432)
npm.stream.incoming_port=25565, npm.stream.forward_port=25565, npm.stream.tcp=true

# CLI One-Liner for LXC:
pct set 101 -tags "npm.domain=adguard.homelab.arpa,npm.port=80,npm.ssl=true,npm.websocket=true"

# CLI One-Liner for QEMU VM:
qm set 200 -tags "npm.domain=homeassistant.homelab.arpa,npm.port=8123,npm.ssl=true,npm.websocket=true"

📝 Method 2: Proxmox Notes / Description Textarea (Full YAML Block)

In the Proxmox Web GUI, select your LXC or VM, click Notes (or Summary → Description), and paste a complete YAML configuration block: 

# ==============================================================================
# Proxmox VE Auto-Discovery Metadata (Paste into LXC / VM Notes textarea)
# ==============================================================================

# Core Ingress Routing (Required)

npm.port: 8000
npm.scheme: http
npm.path: /                          # Optional subpath prefix (e.g. /api)

# SSL & Security

npm.ssl_forced: true                 # Redirect HTTP -> HTTPS automatically
npm.hsts: true                       # Enable HTTP Strict Transport Security
npm.hsts_subdomains: false           # Include subdomains in HSTS
npm.block_exploits: true             # Enable common exploit blocking

# Middlewares & Performance
npm.websocket: true                  # Allow WebSocket upgrade headers (Home Assistant / Plex)
npm.http2: true                      # HTTP/2 multiplexing support
npm.caching: false                   # Nginx reverse proxy asset cache
npm.access_list_id: 1                # Optional NPM Access List ID (Basic Auth / IP whitelist)
